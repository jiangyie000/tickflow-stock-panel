# 本地 stockdb SDK API 文档

> 本文档基于实际本地源码 [stockdb/pybao/stock_sdk.py](../) (802 行) + [stockdb/pybao/zhibiao.py](../) (569 行) 整理, 描述本地 Python SDK (`stock_sdk`) 的每一个接口, 包含参数、返回类型、真实调用示例和常见错误。
>
> 当前版本对应 stockx 后端 V4.2.5+ (2026-08-15) 重构阶段。
>
> 本文档**不包含**在线 API (`get_price` / `get_fundamentals` 等)。在线 API 见 [stockdb/调用方式/python/AI策略python开发接口文档.md](https://...调用方式/python/AI策略python开发接口文档.md) 第 12 节; 本地 SDK 与在线 API 在 `stock_sdk.py` 同名模块里共存, 通过 `set_init()` 切换。

## 0. 阅读须知

1. **本地 SDK 是分层 K-V 数据库的客户端**, 不是 SQL, 也不是 REST. 任何调用必须先确定 `table + K1 + K2...`, 再调用.
2. 日 K 和分钟 K 的固定模板是 `rd.get/vals("日k或分钟k", code, date_query)`, 不能省略 `code` 或 `date_query`.
3. 字符串 `"all"` 不是通配符. 整层匹配使用 `"*"`, 前缀匹配使用 `"6*"`, `"202606*"`.
4. 精确读单条值用 `rd.get()`; 读匹配结果中的值集合优先用 `rd.vals()`; 只要完整键名用 `rd.keys()`.
5. 大范围查询使用代码前缀, 让服务器筛选, 例如 `rd.vals("日k", "6*", date_query)`; **禁止循环 5000 个代码逐股请求**.
6. 需要复权、周/月 K 或分钟聚合时使用 `rd.get_data()`, 不要重新手写复权和周期合成.
7. 39 个技术指标统一入口 `zb.get(name, codes, ...)`, 不要直接调 `zb.MA(...)` 这类低层函数.
8. 板块/概念的双向映射用 `bk.get(x, category, fields)`, 内部已经预热缓存.

## 1. 导入与连接

### 1.1 文件与运行环境

本地 SDK 由两个 Python 文件 + 一个编译二进制 (`stockdb.so`) 组成, 部署在 `stockdb/pybao/` 目录:

```
stockdb/
  pybao/
    stock_sdk.py       # 成品 SDK (入口, 802 行)
    zhibiao.py         # 指标 + 板块 (569 行)
    stockdb*.so        # 编译二进制 (LevelDB + 复权因子 + 板块索引)
    安装.py            # 一次性安装脚本 (写入 .pth, 类似 pip install)
```

本地运行时需要先启动 `stockdb.exe` (本地数据库服务), 默认地址 `127.0.0.1:7899`.

### 1.2 推荐导入

```python
from stock_sdk import rd, bk, zb, init, gp
```

或:

```python
from stock_sdk import *
```

### 1.3 init() — 配置默认连接

```python
def init(
    host: str = "127.0.0.1",
    port: int = 7899,
    socket_timeout: Optional[int] = None,
    password: Optional[str] = None,
    warm: bool = True,
) -> Any:
    """Configure the SDK default endpoint and optionally prewarm SDK data.

    - socket_timeout: None → localhost 默认 1s, 远端默认 3s
    - warm=True (默认): 预加载 复权 因子 + 板块 索引
    """
```

**调用时机**: 默认本地地址 (127.0.0.1:7899) 不需要调用; 切换远端才需要.

```python
# 远端部署示例
from stock_sdk import init
init(host="192.168.31.145", port=7899, warm=True)
```

### 1.4 模块级单例

| 单例 | 类型 | 实际指向 | 来源 |
|---|---|---|---|
| `gp` | `_DefaultClientProxy` | 转发到 `StockDBClient` 高级 facade | `stock_sdk.py:797` |
| `rd` | `_DefaultRdProxy` | 转发到 raw 二进制 `stockdb` (LevelDB) | `stock_sdk.py:798` |
| `bk` | `_LazyZhibiaoExport("bk")` | 懒解析到 `zhibiao.bk` = `BoardIndex` | `stock_sdk.py:799` |
| `zb` | `_LazyZhibiaoExport("zb")` | 懒解析到 `zhibiao.zb` = `ZhiBiao` | `stock_sdk.py:800` |

- `gp` 和 `rd` 都暴露 `get_data` / `get_data_async` 快捷方式 (指向 `StockDBClient`).
- `rd.<其他属性>` 全部转发到 raw 二进制接口 (`rd.vals` / `rd.get` / `rd.keys` / `rd.set` / `rd.pipe` / `rd.mget` 等).

## 2. 数据模型 (rd 是分层 K-V)

### 2.1 物理模型

```text
table : key1 : key2 : ... : keyN  →  value
```

### 2.2 本地 SDK 内置表

| 表名 | K 结构 | Value 形状 | 说明 |
|---|---|---|---|
| `日k` | `code : YYYYMMDD` | dict | 日 K 线 |
| `分钟k` | `code : YYYYMMDDhhmmss` | dict | 分钟 K 线 (14 位时间戳) |
| `复权` | (前缀 `复权*`) | dict | 复权因子; `rd.get("复权*").get("cum")` 拿累计因子 |
| `板块` | (前缀 `板块*`) | dict | 板块/概念/行业索引, `bk.get(...)` 内部读取 |
| `股票代码` | (无 key) | `{prefix: [codes]}` | 全市场股票代码按首位分组 |
| `退市` | (无 key) | (结构待验证) | 退市清单 |
| `delisted` | (无 key) | (结构待验证) | 退市清单 (别名) |

用户私有表: `./mydb/` 目录下任意表名, 例如 `rd.set("我的数据", "600633", "20270101", {...})`.

### 2.3 K 线行典型字段

`rd.vals("日k", code, date_query)` 返回的每一行是一个 dict, 通常包含:

```text
date           # 整数 20260625
code           # 字符串 "600633"
open           # float
high
low
close
volume         # 成交量 (股)
amount         # 成交额 (元)
pct_chg        # 涨跌幅 (%)
amplitude      # 振幅 (%)
turnover       # 换手率 (%)  — 来自 stockdb 原数据, 写入 t_stock_daily 时映射到 turnover_rate
vol_ratio      # 量比
pe_ttm         # 市盈率 (TTM)
pb             # 市净率
total_mv       # 总市值
float_mv       # 流通市值
float_share    # 流通股本
total_share    # 总股本
is_st          # 是否 ST (0/1)
```

(具体哪些字段每次必返回取决于 stockdb 数据端的写入情况, 缺字段时返回 None).

## 3. rd 接口清单

### 3.1 读: `rd.get / rd.vals / rd.keys / rd.len`

```python
# 精确读单值
row = rd.get("日k", "600633", "20260625")
# row = {'date': 20260625, 'code': '600633', 'open': ..., 'close': ..., ...}

# 读匹配值集合
rows = rd.vals("日k", "600633", "20260625")
# rows = [{...}]

# 读完整键名 (不含 Value)
keys = rd.keys("日k", "600633", "20260625")
# keys = ["日k:600633:20260625"]

# 读匹配键 + Value 列表对
pairs = rd.get("日k", "600633", "2026062*")
# pairs = [["日k:600633:20260622", {...}], ...]

# 长度
n = rd.len("日k", "600633", "2026062*")
```

| 方法 | 精确键 | 通配键 | 返回 |
|---|---|---|---|
| `rd.get(t, k1, k2)` | 1 个 Value | K1/K2 为 `*` 时返回 `[[key, value], ...]` | 标量 or 列表对 |
| `rd.vals(t, k1, k2)` | `[Value]` (1 个元素) | K1/K2 为 `*` 时返回 `[Value, ...]` | list |
| `rd.keys(t, k1, k2)` | `[key]` | K1/K2 为 `*` 时返回 `[key, ...]` | list[str] |
| `rd.len(t, k1, k2)` | 1 | 匹配的总数 | int |

### 3.2 Key 查询语法

```python
# 精确匹配
rd.vals("日k", "600633", "20260625")

# 整层与前缀匹配
rd.vals("日k", "600633", "*")           # 该股全部日 K
rd.vals("日k", "600633", "202606*")     # 2026 年 6 月
rd.vals("日k", "6*", "20260625")        # 6 开头证券的某日
rd.vals("分钟k", "60042*", "20260625145200")

# 范围与顺序: < 升序, > 降序
asc  = rd.vals("日k", "600633", "20260620<20260626")
desc = rd.vals("日k", "600633", "20260620>20260626")

# 开放区间使用 N
after  = rd.vals("日k", "600633", "20260620<N")
before = rd.vals("日k", "600633", "N>20260626")

# 表名前缀匹配
rd.vals("退市*")
```

**注意**:
- `"*"` 是整层或后缀前缀匹配, 不是任意位置 glob.
- `<` `>` `N` 是查询字符串的一部分, 不是 Python 比较运算.

### 3.3 写: `rd.set / rd.setr / rd.setl / rd.delete / rd.mset (via pipe)`

```python
# 单条写 (同步)
rd.set("我的数据", "600633", "20270101", {"score": 83.5, "enabled": True})

# 单条写 (异步)
await rd.set("我的数据", "600633", "20270101", {...})

# 强制覆盖 / 不覆盖 / 追加 (类似 Redis SETX/SETNX/SETAPPEND)
rd.setr("我的数据", code, date, value)  # set if exists
rd.setl("我的数据", code, date, value)  # set if not exists

# 删除
rd.delete("我的数据", "600633", "20270101")

# 批量写入必须用 pipe (见 3.5)
```

Key 层级限制 0-2 层, 多余 K 会被忽略. 推荐结构:

```text
table:code:date  →  value           # 单条行情/因子
table:strategy_id:date  →  value     # 策略状态
table:user_id:code  →  value          # 用户标记
```

### 3.4 QueryResult: 服务端字段投影 + 切片

`rd.get/vals/keys/len/delete/set` 返回的对象都是 `QueryResult`, 可以链式追加操作后再执行:

```python
# 字段投影在服务器完成
dates = rd.vals("日k", "600633", "2026062*").get("date").do()
# dates = [20260622, 20260623, ...]

matrix = rd.vals("日k", "600633", "2026062*").get("date,code,close,volume").do()
# matrix = [[20260622, '600633', 11.05, 25847142], ...]

# 切片在服务器完成
first_3 = rd.vals("日k", "600633", "20260620<N")[:3]   # 最新 3 条
last_5  = rd.vals("日k", "600633", "20260620<N")[-5:]

# 链式组合
matrix = rd.vals("日k", "600633", "20260620<N")[-20:].get("date,close").do()

# 调试: 查看实际请求 URL
print(rd.vals("日k", "600633", "2026062*").url())
# /?cmd=vals&t=日k&k1=key:600633&k2=fwd:2026062*
```

**重要**: `.get("date,code,close")` 是服务端字段投影, **不是** Python 端二次筛选. 应当拼到请求里, 不要先 `.do()` 再 `.get()`.

### 3.5 rd.pipe() — 批量管道

用于多个离散精确键的批读写, 不能用前缀/范围覆盖时:

```python
# 同步批量读
pipe = rd.pipe()
for code in ["600633", "600422", "000001"]:
    pipe.mget("分钟k", code, "20260625145200")
rows = pipe.do()
# rows = [{...}, {...}, {...}]

# 异步批量写
async def save_factors(items):
    pipe = rd.pipe()
    for item in items:
        pipe.mset("动态因子", item["factor"], item["code"], item["date"], item["value"])
    await pipe
```

**禁止**循环里逐条 `await rd.set(...)` — 必须用 pipe.

### 3.6 rd.get_data — 加工后的行情接口 (核心)

```python
def get_data(
    code,                  # 必填: str 或 List[str]
    start=None,            # 8 位或 14 位字符串, None = 全量
    end=None,              # 8 位/14位/'N'
    frequency="1d",        # 1d/1m/5m/15m/30m/60m/1w/1M
    fields=None,           # None/逗号字符串/字段列表
    limit=None,            # 每个查询结果最大记录数
    desc=False,            # False 升序, True 降序
    as_df=False,           # False 返回 list/dict, True 返回 DataFrame
    fq="qfq",              # qfq 前复权 / hfq 后复权 / None 不复权
) -> Union[List[Dict], Dict[str, List[Dict]], pd.DataFrame]:
```

**异步同款**: `rd.get_data_async(...)` 参数相同, 返回 awaitable.

#### 3.6.1 日期语义

| 传入 | 含义 |
|---|---|
| `start=None, end=None` | 查询全量 |
| 日 K 只传 8 位 `start` | 查询该精确交易日 |
| 分钟 K 只传 14 位 `start` | 查询该精确分钟键 |
| 分钟 K 查询整天 | 同时传入相同的 8 位 `start/end` |
| 查询从某日到最新 | `start='20260625', end='N'` |
| **只传 `end`** | 当前接口**不会**自动解释为 "从最早到 end", 禁止 |

#### 3.6.2 返回结构

```python
# 单代码, 不传 fields: list[dict]
rows = rd.get_data("600633", start="20260625", end="20260626", fq=None)
# rows = [{'date': 20260625, 'code': '600633', 'open': ..., 'close': ..., ...}, ...]

# 多代码, 不传 fields: {code: [dict]}
rows_by_code = rd.get_data(
    ["600633", "600422"],
    start="20260625",
    end="20260626",
    fq=None,
)
# rows_by_code = {'600633': [...], '600422': [...]}

# 单代码, 传 fields: 位置数组 (二维)
dates = rd.get_data("600633", start="20260625", end="20260626", fields="date", fq=None)
# dates = [[20260625], [20260626]]

matrix = rd.get_data("600633", start="20260625", end="20260626",
                     fields="date,code,close", fq=None)
# matrix = [[20260625, '600633', 10.45], [20260626, '600633', 10.50]]

# 多代码 + fields: {code: [[...]]}
# {'600633': [[20260625, 10.45], ...], '600422': [...]}

# as_df=True: 合并后的 DataFrame (单/多代码统一为长格式)
df = rd.get_data(["600633", "600422"], start="20260625", end="20260626",
                 fields="date,code,close", as_df=True, fq=None)
# df = pandas.DataFrame with columns ['date', 'code', 'close']
```

**注意**: 多代码 `as_df=True` 返回的是合并后的 DataFrame, **不是** `{code: DataFrame}`.

#### 3.6.3 周期与复权

`frequency` 支持: `1d` (日), `1m` / `5m` / `15m` / `30m` / `60m` (分钟), `1w` (周), `1M` (月).

`fq` 支持: `qfq` 前复权 (默认), `hfq` 后复权, `None` 不复权.

复权和周期加工由 SDK 内部完成, **不要**自己对结果手动聚合或二次复权.

#### 3.6.4 大批量使用

```python
# 推荐: 一次传整个代码列表
rows_by_code = rd.get_data(
    codes,             # List[str], 例如全市场 ~5200 只
    start="20260701",
    end="20260807",
    frequency="1d",
    fq="qfq",
)
```

如果只需要原始、不复权、固定日期范围的数据, 前缀 `rd.vals()` 通常更直接、更省请求.

**禁止**: 循环对每只股票单独调用 `rd.get_data` — 单次传代码列表, 或按内存能力分成少量大块.

## 4. bk 接口清单 — 板块/股票双向映射

### 4.1 签名

```python
def get(
    x=None,          # 股票代码 / 板块代码 / 板块名称 / 代码列表 / None
    category=None,   # 0/1/2/3 或中文类别
    fields=None,     # 单字段或逗号字段串

```

### 4.2 类别

| 值 | 类别 | 典型数量 |
|---|---|---|
| `0` | 概念 | ~978 个 |
| `1` | 申万一级 (行业) | 28 个 |
| `2` | 申万二级 | 104 个 |
| `3` | 申万三级 | ~300 个 |

### 4.3 股票查板块

```python
# 单股 → 该股的板块 dict 列表
boards = bk.get("600633", 1)
# boards = [{'code': '801760.SL', 'name': '传媒', 'source': 'sw', 'type': 'sw_1', 'group': '申万行业指数列表', 'category': '申万一级'}]

# 单股 → 该股的行业名 (list[str])
names = bk.get("600633", 1, "name")
# names = ['传媒']

# 单股 → 多字段位置数组
values = bk.get("600633", 1, "group,name")
# values = [['申万行业指数列表', '传媒']]

# 单股 → 所有概念 (list[str])
concepts = bk.get("600633", 0, "name")
# concepts = ['AIGC概念', 'AI应用', 'AI智能体', ...]

# 多股 → {code: [行业名]} 字典
mapping = bk.get(["600633", "000007"], 1, "name")
# mapping = {'600633': ['传媒'], '000007': ['通信']}
```

### 4.4 板块查股票

```python
# 概念名 → 该概念代码
code = bk.get("5G", 0, "code")
# code = '300843.TI'

# 概念名 → 成分股代码列表
symbols = bk.get("5G", 0, "symbols")
# symbols = ['000016', '000049', '000007', ...]

# 行业名 → 成分股
symbols = bk.get("交通运输", 1, "symbols")

# 精确板块代码 → 完整板块 dict (含 symbols)
board = bk.get("801170.SL")
```

### 4.5 名称模糊匹配与分类全集

```python
# 模糊匹配 (按板块名包含关系)
names = bk.get("电池", 0, "name")
# names = ['BC电池', 'HJT电池', 'TOPCON电池', ...]

# 分类全集
boards = bk.get(category=1, fields="name,code")
# boards = [['交通运输', '801170.SL'], ['休闲服务', '801210.SL'], ...]
```

**注意**: 多字段始终返回位置数组, 不要把 `fields="name,code"` 的结果误写成纯名称列表.

### 4.6 允许的字段

```text
code, name, source, type, group, category, symbols
```

(`zhibiao.py:41` `BOARD_FIELDS`)

### 4.7 缓存

首次调用 `bk.get(...)` 会预加载所有板块 (内部读 `rd.get("板块*").do()`), 之后纯内存查询. 如需强制重新加载:

```python
from stock_sdk import bk
bk.reset()  # 丢弃缓存, 下次 get 重新读 LevelDB
```

## 5. zb 接口清单 — 批量技术指标 + 指数

### 5.1 签名

```python
def get(
    name,                                    # 指标名 (str 或逗号串 / list)
    codes=None,                              # str 或 List[str]
    original=None,                           # 内存行情 (替代 codes)
    start=None,
    end=None,
    frequency="day",                         # 'day' 或 '1d'/'1m'/...
    method=1,                                # 指数权重 (zhishu 专用)
    base=1000.0,                             # 指数基准 (zhishu 专用)
    fq="qfq",
    fields=None,                             # 基础指标的输入字段
    n=None,                                  # 指标参数 (str/int/list)
    cross=False,                             # True / False / "with_value"
) -> Union[List[Dict], Dict[str, List[Dict]]]:
```

### 5.2 代码取数模式 vs 内存模式

**模式 A: 代码取数** (zb 自行拉行情)

```python
macd = zb.get(
    "macd",
    ["600633", "000007"],
    start="20260601",
    end="20260630",
    frequency="1d",
)
# macd = {'600633': [{'date': 20260625, 'dif': ..., 'dea': ..., 'macd': ...}, ...], '000007': [...]}
```

**模式 B: 内存模式** (传入已拉好的行情, 避免重复请求)

```python
kdata = rd.get_data(["600633", "000007"], start="20260601", end="20260630",
                    fields=None, fq="qfq")
# kdata = {'600633': [{date, open, high, low, close, volume, amount, ...}], '000007': [...]}

macd = zb.get("macd", original=kdata)
# 等价于模式 A, 但不重新读 DB
```

**重要**: 模式 B 时 `start/end/frequency/fq` **不会**再次应用, 原始数据采用什么周期和复权, 指标就基于什么数据计算. 但 `n/fields/cross/method/base` 仍是指标计算参数.

**禁止**: 给 zb 传无列名的位置矩阵 (例如 `rd.get_data(..., fields="date,open,...")` 返回的二维数组). 因为位置矩阵不携带列名, zb 无法知道每一列对应什么字段.

### 5.3 日期语义

**代码取数模式下**: 必须明确传 `start/end`. 当前默认 `start` 是固定值 `20260302`, 不传 `end` 只会读默认开始日这一精确日, **不代表**全量历史.

```python
# 正确
zb.get("macd", "600633", start="20260601", end="20260630", frequency="1d", fq="qfq")

# 错误: 不传 start/end, 只会读 20260302 这天的数据
zb.get("macd", "600633")
```

`start='20260601', end='N'` 表示从 20260601 到最新.

### 5.4 返回结构

```python
# 单代码: list[dict]
result = zb.get("macd", "600633", start="20260601", end="20260630")
# result = [{'date': 20260625, 'dif': ..., 'dea': ..., 'macd': ...}, ...]

# 多代码: dict[str, list[dict]]
result = zb.get("macd", ["600633", "000007"], start="20260601", end="20260630")
# result = {'600633': [...], '000007': [...]}
```

每只股票内部按 `date` 升序独立计算, **不要求**不同股票日期完全对齐.

### 5.5 多指标

```python
studies = zb.get(
    "ma,kdj,macd",
    ["600633", "000007"],
    start="20260601",
    end="20260630",
    frequency="1d",
    n=["5,10,20", None, "12,26,9"],
)
```

或:

```python
zb.get(["ma", "kdj", "macd"], "600633", ...)
```

**注意**: 多指标时, `n` 必须与指标名称一一对应, 不能把 `n="5,10,20"` 直接用于三个不同指标.

### 5.6 cross 参数

```python
# 仅信号 (1=金叉, -1=死叉, 0=无)
signals = zb.get("ma,kdj,macd", ["600633", "000007"],
                 start="20260601", end="20260630",
                 n=["5,10,20", None, "12,26,9"], cross=True)

# 信号 + 指标值
with_values = zb.get("ma,kdj,macd", ["600633", "000007"],
                     start="20260601", end="20260630",
                     n=["5,10,20", None, "12,26,9"], cross="with_value")

# 仅指标值 (默认)
values = zb.get("ma,kdj,macd", ..., cross=False)
```

多指标综合 `cross=True`: 返回布尔值, 所有单项同一根 K 线都为金叉时为 `True`, 否则为 `False`; **不是**综合死叉字段.

### 5.7 基础指标的 `fields` 参数

只有以下基础指标支持 `fields` (用作输入字段):

```text
ma, ema, sma, wma, dma, std, sum, hhv, llv, ref
```

可选输入字段:

```text
close, high, low, open, volume, amount, float_mv, total_mv
```

```python
volume_ma = zb.get("ma", "600633", start="20260601", end="20260630",
                   n="5,10", fields="volume")
```

### 5.8 支持的指标 (39 个)

### 5.9 指数 zhishu

```python
index_rows = zb.get(
    "zhishu",
    ["600633", "000007"],
    start="20260601",
    end="N",
    frequency="1d",
    method=1,    # 1=等权, 2=流通市值, 3=成交额, 4=成交量, 5=总市值
    base=1000,
)
```

| method | 权重 |
|---|---|
| `1` | 等权 |
| `2` | 流通市值 |
| `3` | 成交额 |
| `4` | 成交量 |
| `5` | 总市值 |

当前实现只有 `frequency='1d'` 支持 `method=2/5`; 其他周期使用 `1/3/4`. 指数需要前一根有效收盘价, 因此结果会去掉无法形成收益的第一期, 必须按 `date` 对齐.

### 5.10 低层数组函数

```python
close = [10.0, 10.2, 10.1, 10.5]
high  = [10.1, 10.3, 10.2, 10.6]
low   = [9.9, 10.0, 10.0, 10.2]

dif, dea, macd = zb.MACD(close, 12, 26, 9)
k, d, j = zb.KDJ(close, high, low, 9, 3, 3)
cross = zb.CROSS(dif, dea)
```

低层函数是同步计算, **不会**读取数据库. 初始周期可能出现 `nan`, 统计前使用 `math.isfinite()` 过滤.

## 6. gp 接口 — 高级 facade

`gp` 是 `StockDBClient` 的懒代理, 暴露以下方法 (来源 `stock_sdk.py:50-668`):

| 方法 | 签名 | 说明 |
|---|---|---|
| `get_data(...)` | 同 `rd.get_data` | 转发到共享 `StockDBClient` |
| `get_data_async(...)` | 同 `rd.get_data_async` | 异步同款 |
| `build_time_query_for_retrieval(start, end, desc, frequency)` | → str | 把 8 位日期提升为 14 位时间戳 (分钟 K 用) |

私有方法 (一般不需要直接调):

| 方法 | 说明 |
|---|---|
| `_build_time_query(start, end, desc)` | 构建 LevelDB 范围表达式 `"<s><op><e>"` |
| `_filter_fields(data_list, fields)` | 投影 dict 行到指定字段 |
| `_to_dataframe(data, is_batch, fields=None)` | 包装成 `pd.DataFrame` |
| `_merge_to_period(daily_data, frequency)` | 日 K → 周 K / 月 K |
| `_merge_minutes_to_period(minute_data, frequency)` | 1 分钟 → 5m/15m/30m/60m |
| `_apply_fq_in_memory(code, records, fq_type)` | 内存里做前/后复权 |

**实际推荐**: 直接用 `rd.get_data` / `rd.get_data_async`, 不用 `gp`.

## 8. 常见错误清单

### 8.1 错误: `all` 当通配符

```python
rd.get("日k", "all")       # "all" 只是一个普通字符串键
```

正确:

```python
rd.vals("日k", "600633", "*")  # 整层匹配使用 "*"
```

### 8.2 错误: 少一个日期参数

```python
rd.get("日k", "600633")  # 日 k 还缺少日期这一层
```

正确:

```python
rd.vals("日k", "600633", "*")        # 全部日期
rd.vals("日k", "600633", "20260625") # 单日
```

### 8.3 错误: 全市场逐股请求

```python
for code in all_codes:
    row = rd.get("日k", code, date)  # 5000 次独立请求
```

正确:

```python
prefixes = ["0*", "3*", "6*", "920*"]
rows = []
for prefix in prefixes:
    part = rd.vals("日k", prefix, date).do()
    rows.extend(part)
```

或:

```python
rows_by_code = rd.get_data(all_codes, start=date, end=date, frequency="1d", fq="qfq")
```

### 8.4 错误: 把 Python get_data 单字段当标量数组

```python
dates = rd.get_data(..., fields="date")
# dates 是 [[date], ...], 不是 [date, ...]
```

正确:

```python
dates = [row[0] for row in rd.get_data(..., fields="date")]
# 或
rows = rd.get_data(..., fields=None)  # 不传 fields, 返回 list[dict]
dates = [r["date"] for r in rows]
```

### 8.5 错误: 给 zb 传无列名的位置矩阵

```python
kdata = rd.get_data(..., fields="date,open,high,low,close,volume")
zb.get("macd", original=kdata)  # 错误: 无法知道每一列对应的字段
```

正确:

```python
kdata = rd.get_data(codes, start=start, end=end, fields=None, fq="qfq")
zb.get("macd", original=kdata)

# 或让 zb 按代码自行取数
zb.get("macd", codes, start=start, end=end)
```

### 8.6 错误: 省略 zb 日期

```python
zb.get("macd", "600633")  # 只会使用固定默认开始日 20260302, 不是全量
```

正确:

```python
zb.get("macd", "600633", start="20260601", end="20260630", frequency="1d")
```

### 8.7 错误: 批量数据逐条写入

```python
for item in items:
    await rd.set("动态因子", item["code"], item["date"], item)
```

正确:

```python
pipe = rd.pipe()
for item in items:
    pipe.mset("动态因子", item["code"], item["date"], item["value"])
await pipe
```

### 8.8 错误: 误解 QueryResult.get

```python
# 正确: 服务端字段投影
rows = rd.vals("日k", "600633", "2026062*").get("date,code,close").do()

# 错误: 先全量下载再 Python 端二次筛选
all_rows = rd.vals("日k", "600633", "2026062*").do()
filtered = [r for r in all_rows if r["date"] > 20260620]
```

### 8.9 错误: 自行创建其他数据库

```python
import sqlite3
import duckdb
from sqlalchemy import create_engine
```

**禁止**: 策略存储、缓存、因子、私有数据严禁使用第二套数据库. 统一改为 `rd.set()` / `rd.pipe().mset()` / `rd.get/vals()`, 数据保存到 `./mydb`.

## 10. 性能规则 (本地 SDK 角度)

无论上层用 FastAPI / PySide / Streamlit / 命令行脚本, 数据规则不变:

1. **数据读取和指标计算与界面渲染分离**.
2. **窗口重绘、排序、筛选和翻页只操作内存结果** — 不要每次重绘都重拉 DB.
3. **大范围原始行情优先使用 `rd` 前缀查询** (`rd.vals("日k", "6*", "20260801<N>")`).
4. **离散精确键使用 `rd.pipe()` + `mget()`**.
5. **复权和周期数据使用 `rd.get_data()` 代码列表接口** (`rd.get_data([...], start, end, fq="qfq")`).
6. **在线 API 只做单标的、小数据补充** — 不用于大批量历史行情.
7. **后台线程或异步任务完成后再更新 UI**, 不能在鼠标移动事件中同步请求网络.
8. **平均值、金叉数量等汇总对完整筛选结果计算**, 不能只计算当前可见控件.
9. **所有需要跨进程、跨重启保留的数据都写入 `rd + ./mydb`**.
10. **多条私有数据使用 `rd.pipe().mset(...)` 批量提交**, 不能逐条网络写入.
11. **缓存**: `functools.lru_cache(maxsize=32)` 或自定义字典缓存; 缓存键至少包含 `codes/start/end/frequency/fields/limit/desc/fq`.
